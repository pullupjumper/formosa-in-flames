# 專案規範文件 (Project Specification)

## 專案概述

**Formosa in Flames** 是一個使用 Lua 語言開發的 Command: Modern Operations (CMO) 軍事模擬場景，模擬台海衝突情境。該專案展現了專業級 Lua 程式設計結合深度軍事領域專業知識的複雜軍事模擬系統。

### 核心特性
- **多方陣營協調**: 中國、台灣、美國三方軍事行動模擬
- **先進軍事系統**: 空中作戰指令 (ATO)、電子戰、兩棲攻擊作戰
- **事件驅動架構**: 基於模組化設計的即時軍事作戰模擬
- **動態火力支援計畫**: 基於戰損評估 (BDA) 的自動化火力支援執行矩陣 (FSEM)

## 技術架構

### 程式語言與環境
- **主要語言**: Lua 5.1+ (CMO 環境)
- **型別系統**: LuaLS 標註系統，提供編譯期型別檢查
- **測試框架**: Busted (BDD 風格測試)
- **建構工具**: Python 建構腳本 (模組處理和部署)

### 專案結構
```
formosa-in-flames/
├── src/                    # 主要原始碼
│   ├── core/              # 核心系統
│   ├── modules/           # 功能模組
│   ├── scripts/           # 陣營特定事件處理

```

## 核心設計原則

### 1. 模組化與可維護性
- **單一職責**: 每個模組專注特定軍事功能
- **依賴注入**: 透過 require() 系統管理模組依賴
- **介面抽象**: 統一的 API 包裝層

### 2. 型別安全與可靠性
- **LuaLS 標註**: 完整的型別定義和參數檢查
- **錯誤處理**: 統一的 SafeCall 包裝器處理異常
- **重試邏輯**: 針對 CMO API 時序問題的容錯機制

### 3. 軍事領域建模
- **真實軍事概念**: 實作現代戰爭的複雜作戰模式
- **編隊管理**: 幾何演算法實現軍事編隊定位
- **任務協調**: 多層次任務分配和執行監控

### 4. 配置管理
- **中央化配置**: `constants.lua` 集中管理所有參數
- **命名空間結構**: 按陣營 (.c, .t, .u, .s) 組織配置
- **平台資料庫**: 軍事裝備 DBID 和基地 GUID 常數化

## 開發模式與工作流程

### 開發環境設定
1. **開發模式**: 設定 `config.isDevMode = true` 啟用除錯功能
2. **日誌系統**: 雙語日誌自動偵測遊戲/開發環境
3. **測試執行**: 使用 `busted` 執行單元測試

### 建構與部署
1. **模組處理**: `build_lua_scenario.py` 移除 require 並清理模組
2. **程式碼合併**: 產生單一部署檔案
3. **驗證測試**: 部署前執行完整測試套件

### 品質保證
- **測試覆蓋**: 部分核心模組有對應測試
- **API 模擬**: 遊戲 API 模擬用於測試
- **配置驗證**: 結構化驗證配置參數
